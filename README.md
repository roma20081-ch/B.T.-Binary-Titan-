## 🚨 Важное предупреждение
Проект находится в состоянии **Pre-Alpha**.  
Разрабатывается через **"Вайб-код"** (экспериментальный подход без строгой архитектуры), поэтому возможны **критические баги**, утечки памяти и нестабильная работа.  

**Внимание:** Бот имеет доступ к вашей ОС. Используйте только в тестовой среде!

---

## 📖 Описание
**Binary Titan (BT)** — это Discord-бот, который подключается к локальной нейросети (через **Ollama**) и выполняет команды на вашем ПК.  
Главная фишка: **полная автономность** (не требует платных API) и возможность управлять окнами, процессами и даже голосовыми каналами.

### 🧠 Используемые модели AI
- `llama3.2` / `и другие по выбору` — для общих вопросов.
- `deepseek-coder` /  `и другие по выбору` — для генерации кода.
- Переключение между моделями в реальном времени (команда `!ai`).

## 📋 Список команд

### 🤖 Основные
- `!ask <вопрос>` — Задать вопрос нейросети.
- `!code <задача>` — Генерация кода (используется Coder-модель).
- `!stats` — Статистика использования (токены, время ответа).
- `!help` — Показать эту справку.
- `!ai [fast/medium/hard/coder/auto]` — Переключить активную модель ИИ.

### 🖥️ Управление системой (Осторожно!)
- `!run <программа>` — Запустить разрешённое приложение (белый список).
- `!ps [фильтр]` — Список активных процессов.
- `!kill <PID>` — Принудительно завершить процесс.
- `!screen` — Отправить скриншот экрана в чат.
- `!window` — Показать заголовок активного окна.
- `!close <часть названия>` — Закрыть окно по фрагменту названия.
- `!minimize <часть названия>` — Свернуть окно.
- `!windows` — Вывести список всех открытых окон.

### 🌐 Файлы и интернет
- `!open <имя файла>` — Открыть файл/ярлык с рабочего стола.
- `!site <название>` — Быстрый переход на сайт (поддерживается: вк, ютуб, дипсик).
- `новости [rbc/lenta/ria]` — Получить сводку новостей.
- `найди <запрос>` — Поиск в интернете с пересказом результата.
- `найди по истории <запрос>` — Поиск в браузере Edge.

### 🔊 Звук и голос
- `!volume [0-100]` — Показать или установить громкость системы.
- `!mute` — Включить/выключить беззвучный режим.
- `!join` — Подключиться к вашему голосовому каналу.
- `!listen` — Включить режим прослушки (распознавание речи участников).
- `!stop` — Остановить прослушку.
- `!leave` — Отключиться от голосового канала.

### 📜 Сценарии (Скрипты)
- `!scenario list` — Показать сохранённые сценарии.
- `!scenario add <фраза>: open:хром; volume:100` — Добавить триггерную фразу.
- `!scenario remove <фраза>` — Удалить сценарий.

> **Примечание:** Большинство команд работает и без префикса `!` (упоминание бота в чате).
